# GridBalance

Network-flow imputation benchmark derived from EIA-930 hourly balancing
authority data (U.S. Energy Information Administration, six-month files,
2018-2024). Source data is a U.S. Government work in the public domain
(17 U.S.C. §105). This derived dataset is released under CC0 1.0
(Public Domain Dedication); see LICENSE.

95 anonymized week-long cases (53 train / 42 test): reconstruct hidden
tie-line flows under an exact zone-level conservation law.
